# 你好，我是 Bobibobixuan 

我做 Minecraft 模组，也写一些自己用得上的工具。从给《农夫乐事》加中式菜谱，到批量翻译模组语言文件、在局域网里传文件，这里放着我愿意分享出来的项目。

[个人博客 · Avorenq](https://blog.avorenq.com/) · [全部公开仓库](https://github.com/bobibobixuan?tab=repositories)

## Minecraft 模组与本地化

| 项目 | 能做什么 |
| --- | --- |
| [Farmer Bobi · 波比乐事](https://github.com/bobibobixuan/farmerbobi) | 给《农夫乐事》加入中式与亚洲料理，支持 Minecraft 1.20.1 的 Fabric 和 Forge。 |
| [One Enough](https://github.com/bobibobixuan/One-Enough) | 为 Fabric 整合包处理不同模组之间作物重复、物品 ID 各异的问题。 |
| [Auto MC Translator](https://github.com/bobibobixuan/Auto-MC-Translator) | 用 AI 批量翻译 Minecraft 模组的 JSON 语言文件，保留游戏内的格式代码。 |

## 局域网与机器人

- [Bobi LAN Chat](https://github.com/bobibobixuan/Bobi-LAN-Chat) — 用 Python 写的局域网聊天和文件共享工具，支持自动发现同一局域网内的客户端。
- [Tonybot Motion Workflow](https://github.com/bobibobixuan/tonybot-motion-workflow) — 面向 Tonybot 的动作文件分析、编排检查和 JSON 转 `.rob` 工作流。
